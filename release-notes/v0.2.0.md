# mcp-gitee-ent v0.2.0

新增 Gitee 企业版知识库文档工具，并限制文档上传与下载可访问的本地目录。

## Highlights
- 新增企业文档 MCP 工具：`list_enterprise_documents`、`list_enterprise_document_pages`、`get_enterprise_document_page`、`upload_enterprise_document_files`、`download_enterprise_document`、`update_enterprise_document_page`，支持列出知识库文档、读取页面、导入本地文件、导出文档和更新页面。
- 新增 `GITEE_ENT_MCP_ALLOWED_FILE_ROOTS` 配置，用于限定文档上传和下载可访问的本地绝对目录。

## Improvements
- 文档页面列表会展开层级并返回页面路径、页面类型、内容类型和当前版本，便于读取后连续编辑。
- 文档列表支持分页、排序、按项目过滤，以及仅列出当前用户创建的文档。
- 页面更新会校验 `expected_version`，当版本已变化时拒绝写入，避免覆盖他人修改；也可通过 `page_name` 重命名页面，并通过 `mentioned_user_ids` 提及企业用户。
- 文档导入支持 1 至 20 个 `.zip`、`.html`、`.txt` 或 Markdown 文件，单文件最大 6 MiB，导入内容最多包含 20 个页面；导入结果可能异步生成，需要重新获取页面最终版本。
- 文档导出支持 Markdown、HTML 或 PDF；默认不覆盖已有导出路径，只有显式设置 `overwrite=true` 时才覆盖。

## Security
- 文档上传和下载仅允许访问 `GITEE_ENT_MCP_ALLOWED_FILE_ROOTS` 中已存在的绝对目录；未设置时默认只允许 MCP 服务器当前工作目录及其子目录。
- 文件范围校验会先解析符号链接，同时仍受操作系统权限、容器挂载和沙箱限制约束。

## Upgrade Notes
- 启用文档上传或下载前，请根据部署环境配置 `GITEE_ENT_MCP_ALLOWED_FILE_ROOTS`；多个目录使用当前操作系统的路径列表分隔符分隔，例如 Unix 使用 `:`，Windows 使用 `;`。
- 上传和下载路径指的是运行 MCP 服务器机器上的本地路径，不是 Agent 用户远程机器上的路径。
