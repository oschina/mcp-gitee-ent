# mcp-gitee-ent v0.2.3

统一文档页面与文件夹创建入口，简化企业知识库文档结构管理。

## Highlights

- **新增统一创建工具 `create_enterprise_document_node`**：替代原有的 `create_enterprise_document_page` 和 `create_enterprise_document_folder`，通过必填参数 `type`（值为 `page` 或 `folder`）即可创建页面或文件夹，减少工具数量并统一调用方式。

## Upgrade Notes

- `create_enterprise_document_page` 和 `create_enterprise_document_folder` 已移除，请迁移至 `create_enterprise_document_node`。
- 调用新工具时需新增必填参数 `type`，指定为 `"page"` 创建页面，或 `"folder"` 创建文件夹；其余参数（`enterprise_id`、`document_id`、`name`、`parent_id`）保持不变。
