# mcp-gitee-ent v0.2.1

本版本为知识库文档工具增加关键字搜索能力，并返回页面级命中结果。

## Highlights
- 扩展 `list_enterprise_documents` 工具：新增 `search` 参数，可按关键字查找可访问的企业知识库文档，并以页面为单位返回命中结果。

## Improvements
- 关键字搜索会匹配文档名和页面名；当企业启用全文检索时，还会匹配正文。
- 搜索命中会返回清理后的文档、页面和内容预览信息，便于后续定位页面并继续调用文档页面工具。
- 搜索结果会移除服务端高亮标记、折叠多余空白，并将内容预览截断为最多 300 个字符，避免返回过长正文。
- 传入空白 `search` 时，工具会回退为普通文档列表。

## Upgrade Notes
- 使用 `search` 时，`list_enterprise_documents` 的返回结构会从普通文档列表变为页面级搜索命中列表。
- `search` 不能与 `program_id`、`created_by_me`、`direction` 或 `per_page` 同时使用。
- 关键字搜索结果按服务端固定的降序分页返回；可通过 `page` 翻页，并通过 `sort` 选择排序字段。
