# mcp-gitee-ent v0.2.2

本版本新增企业知识库文档的创建与管理能力，支持从新建文档到页面/文件夹结构维护的完整生命周期操作。

## Highlights

- **新增企业知识库文档创建工具**：`create_enterprise_document` 支持创建企业级或项目级知识库文档，可选指定父文件夹、项目、迭代及访问权限（inherit/private/read_only/read_write）
- **新增文档页面创建工具**：`create_enterprise_document_page` 支持在现有文档内新建页面，可通过 `parent_id` 指定父文件夹实现层级结构
- **新增文档文件夹创建工具**：`create_enterprise_document_folder` 支持在现有文档内新建文件夹，可通过 `parent_id` 嵌套到指定层级
- **新增文件夹重命名工具**：`rename_enterprise_document_folder` 支持重命名现有文档内的文件夹，名称限制 64 个字符且不可包含 `/`

## Improvements

- 文档相关 MCP 工具集从只读查询扩展为完整的读写能力，覆盖文档创建、结构搭建与内容管理
